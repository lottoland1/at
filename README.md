# Lottoland Österreich Link Page

A separate, responsive GitHub Pages version for Lottoland Österreich.

## Included
- `index.html` — Austrian heading, requested nine buttons and divider
- `style.css` — matching compact responsive design
- `images/` — all image assets used by the page

## Publish as a separate GitHub Pages site
1. Create a separate public GitHub repository, for example `lottoland-links-at`.
2. Upload the contents of this folder to the repository root (upload the `images` folder too).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
5. The site will be published at `https://YOUR-USERNAME.github.io/lottoland-links-at/`.

This is a separate site; it does not overwrite the Germany version.
